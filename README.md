# 🤖 Agentic SDLC Framework with GitHub Copilot

**Project Name**: Agentic-SDLC-copilot-Harshali  
**Purpose**: Automated end-to-end software development lifecycle using GitHub Copilot Agents

---

## 🎯 What is This?

This is an **Agentic SDLC Framework** that automates the entire software development lifecycle by simply providing a `user-story.txt` file. The framework orchestrates multiple AI agents to transform requirements into production-ready code.

### What It Does

1. ✅ **Analyze Requirements** from `user-story.txt`
2. ✅ **Create Jira Tasks** and **Confluence Documentation**
3. ✅ **Design Architecture** and technical specifications
4. ✅ **Generate Backend Code** (Spring Boot)
5. ✅ **Generate Frontend Code** (React)
6. ✅ **Write and Execute Tests** (JUnit + React Testing Library)
7. ✅ **Perform Code Review** with quality analysis
8. ✅ **Create Pull Request** on GitHub
9. ✅ **Deploy Locally** for testing

## 🎓 How It Works

### Input: user-story.txt
```
Title: Task Manager Application

User Story:
As a User,
I want to create, view, update, and delete tasks,
So that I can manage my daily to-do list.

Acceptance Criteria:
1. User can add a new task
2. User can view all tasks
3. User can mark a task as completed
4. User can delete a task

Technical Requirements:
- Backend: Spring Boot (Java 17)
- Frontend: React 18+
- Database: H2 in-memory
```

### Output: Complete Application

**Generated Code**:
- Complete Spring Boot backend (`src/`)
- Complete React frontend (`frontend/`)
- All tests (80%+ coverage)
- API documentation (Swagger UI)

**Jira Integration**:
- Epic created with all user stories
- Tasks updated automatically
- Ready for Review status

**Confluence Documentation**:
- Requirements specification
- Architecture design
- API documentation
- Test report
- Code review report
- Final summary

**GitHub**:
- Clean Pull Request
- Detailed description
- Ready for human review

**Local Deployment**:
- Backend: http://localhost:8080

- Swagger: http://localhost:8080/swagger-ui.html
- H2 Console: http://localhost:8080/h2-console

## 🆘 Troubleshooting

### Jira Connection Issues
- Verify `JIRA_BASE_URL` and `JIRA_API_TOKEN` in `.env`
- Check if token has proper permissions
- Ensure VPN connection if required

### Confluence Connection Issues
- Verify `CONFLUENCE_SPACE_KEY` exists (gitHubSpac)
- Check API token permissions

### GitHub PR Creation Issues
- Add `GITHUB_TOKEN` to `.env` file
- Token needs `repo` and `workflow` scopes

### Code Generation Issues
- Ensure Java 17+ and Node.js 18+ installed
- Check Maven and npm are in PATH
- Review logs in `logs/` directory
